## 下载安装时的 3 大安全注意事项

1. **核对文件名与哈希值（SHA256）**：
   在 GitHub 下载 `.exe` 或 `.dmg` 文件时，核对 Release 页面提供的 SHA256 哈希校验码，确保文件未被修改。
2. **认准官方发布账号**：
   例如 Clash Verge 认准 `clash-verge-rev`，v2rayN 认准 `2dust`。切勿下载名称拼写极其相似的第三方衍生镜像。
